# CartCloser AI

A landing page for **CartCloser AI**, a micro-SaaS concept: an AI sales assistant that chats with shoppers on
Shopify and WooCommerce stores and helps them finish checkout.

> This is a design and front-end concept, not a live product.

**Live:** https://cartcloser-ai.vercel.app · **Portfolio:** https://iamsadeq.dev

## Sections
Hero · comparison with ordinary chatbots · how it works · interactive demo preview · pricing · FAQ

## Stack
React 19 · TypeScript · Vite · Tailwind CSS · lucide-react

## Run locally
```bash
npm install
npm run dev
```
Build with `npm run build` (output in `dist/`).
